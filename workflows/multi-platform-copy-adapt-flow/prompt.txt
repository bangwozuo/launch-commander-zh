# 多平台文案适配流程（multi-platform-copy-adapt-flow）

> 触发：事件，主稿/卖点确认后（T-4 至 T-3）
> 产出：各平台原生版本（模型产出）+ 规格校验与双语口径比对清单（脚本产出）
> 价值：省 3h/次 ≈ ¥240/次；X 首条带链接降权、Reddit 忘披露、数字口径漂移——
> 这三类「发完才发现」的事故全部前移到发布前拦截

# 流程目标

主稿进，**五平台原生版本 + 校验全绿**出。platform-format-adapt 负责重写（模型强项），
bilingual-switch 负责双语各自成文（模型强项），本流程做它们做不了的**机器校验**：
字数、tag 数、首条链接、披露声明、双语数字口径——这些是硬规则，模型自判不可信。

# 步骤明细（每步含输入/处理/输出/失败处理）

## 步骤 1：各平台重写（模型位）

| 项 | 内容 |
|---|---|
| 技能 | `platform-format-adapt`（X/V2EX/即刻/小红书重写）+ `bilingual-switch`（英中两版各自成文） |
| 输入 | 主稿（PH 版或产品说明）+ 目标平台 + 受众 |
| 处理 | 拆主稿五零件（钩子/卖点/证据/召唤/花絮）→ 按平台结构重组 → 母语重写（不互译） |
| 输出 | copies[]（platform/title/body/tags/lang 字段） |
| 失败处理 | 语感为模型判断，重要平台（PH/X）建议母语者终审；本流程只校验硬规则 |

## 步骤 2：平台硬规格校验（内置）

| 项 | 内容 |
|---|---|
| 输入 | copies[] |
| 处理 | 逐平台校验：X 正文 ≤280 字符 + tag ≤2 + **首条不带链接**（防降权）；V2EX 标题 ≤40 字；即刻正文 ≤500 字；小红书标题 ≤20/正文 ≤1000；Reddit 检查 **I made this 披露**；未收录平台标「需人工核对官方规格」不编造限制 |
| 输出 | 「平台规格校验」sheet 逐项 ✅/❌/⚠️ |
| 失败处理 | 超长 → ❌ 并给出超出量；链接在首条 → ❌「链接放回复」；披露缺失 → ❌ |

## 步骤 3：双语数字口径比对（内置，红线）

| 项 | 内容 |
|---|---|
| 输入 | lang=en 与 lang=zh 的全部版本 |
| 处理 | 抽取两版数字集合（中文「N万」折算并与英文 100k 对齐）→ 比对差集；一边独有的数字 = 事实漂移 |
| 输出 | 「双语口径比对」sheet：✅ 一致 / ❌ 红线（列两边差异） |
| 失败处理 | 无双语对 → 标「单语言」跳过；数字漂移 → 列差异并处置「数字是两版共同的信任资产，恢复一致」 |

# 量化规则（判定不看感觉）

- 字数上限：X 280 / V2EX 标题 40 / 即刻 500 / 小红书 20+1000——超 1 字也是 ❌
- tag ≤2 个（X）；首条链接 = 降权（链接放回复是唯一正确姿势）
- Reddit 无 I made this 披露 = ❌（被识破 = 版封 + 截图挂人）
- 数字口径：两边数字集合必须完全一致（0.3s vs 0.3 秒对齐；10 万 vs 100k 折算对齐）
- 规格基线时效：平台规则会更新，以官方最新为准；未收录平台不猜

# 失败模式（编排层特有）

- **自判字数**：模型数自己写的字数不可信——「差不多 280」与「实测 292」差一次限流；
  本流程只认脚本统计
- **链接顺手贴**：X 文案最后顺手带上官网链接是最常见降权原因——独立检查项专治手滑
- **双语各写各的**：重写（非互译）的副作用是事实漂移——英文版删了「10 万条实测」
  中文版留着，两版可信度不对等；数字比对专治这个
- **中文数字不统一**：一版写「3 个月」另一版写「三个月」——机器比对不了中文数字，
  须在重写规范里统一用阿拉伯数字（bilingual-switch 自查清单第 4 条）

# 输出格式（适配校验清单）

```markdown
## 平台规格校验

| 平台 | 检查项 | 结果 | 说明 |
|---|---|---|---|

## 双语口径比对

| 比对 | 结果 | 仅英文版出现 | 仅中文版出现 | 处置 |
|---|---|---|---|---|

## 汇总

| 项 | 内容 |
|---|---|
| 整体判定 | ✅ 全部通过 / ❌ n 项未过 |
```

# 编排规则

- DAG 节点 = 本仓真实技能 slug：`platform-format-adapt`（重写位）→
  `bilingual-switch`（双语位）→ 内置校验 ×2（脚本）
- 产出版本回填 publish-calendar-flow 的时点表（哪个版本几点发）
- 校验不过 → 回到重写位修正，不人工微调绕过（字数超了就重写那一段）

# 合规

- 输出标注「AI 生成内容」；各平台版本人工确认后发布
- Reddit 披露利益相关为硬要求，流程代查但责任在发布者
- 平台 AIGC 标识按现行要求执行；平台规格以官方最新为准
