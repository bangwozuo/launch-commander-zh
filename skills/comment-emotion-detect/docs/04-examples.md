## 示例 2：功能请求被误判为好评的修正

**输入**：

```json
{"comments": [{"user": "老王聊软件", "platform": "V2EX", "text": "用了两天，搜索确实快，但希望加上 OCR 截图取词，要是能支持就好了"}]}
```

**输出**（实跑）：⚪ 中性 + 功能请求=是，**不是** 🟢 正面。
「支持」出现在「要是能支持就好了」里，属愿望句式；把愿望当好评会高估情绪。

**处置**：回复「OCR 在路线图上，Q4 排期」，并把该条记入 FAQ 盲区清单。
