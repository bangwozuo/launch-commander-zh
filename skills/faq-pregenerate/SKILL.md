# FAQ 预生成

T-3 扮演最难缠的访客，把发布日会被问、会被怼的问题提前打完，产出**可直接粘贴**
的应答口径库。发布日评论 30 分钟内要回——没有口径库就只能现场抓瞎。

不做的事：不替开发者定商业口径（定价变更/开源承诺/日期承诺转人工）。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_02_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 发布指挥官 |
| 能力族 | 文案生成型 · 质疑预演与应答口径库 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高（更新发布/客服库复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **六类质疑预演**：价值（竞品对比）/ 价格（为什么收费/不开源）/ 隐私（数据流向）/
   可持续性（跑路质疑）/ 平台（兼容与排期）/ 边界（真实上限数字），每类 ≥2 条
2. **应答三层结构**：直接回答（含关键数字）→ 一句话支撑 → 钩子续对话
3. **攻击性预演**：往狠里问（换皮/敢用吗），攻击性问题占比 ≥1/3
4. **覆盖度量化**：基础库 ≥15 条；不达标列补充清单
5. **口径一致性**：与落地页/README 逐字核对；英文社区重写不互译，事实口径一字不差
6. **升级清单**：定价变更/法律/承诺日期标「需开发者定夺」，FAQ 不擅自定口径

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `subject` | string | ✅ | 产品说明：核心功能、定价、平台、竞品、开发形态 |
| `known_questions` | array | ⬜ | 已知高频问题（历史评论/waitlist 邮件/内测群） |
| `launch_context` | string | ⬜ | 发布时点与目标社区 |
| `audience` | string | ⬜ | 目标受众 |

## 输出规格

| 件 | 说明 |
|---|---|
| `qa_list` | 问答清单：类/问题/触发关键词/应答口径/覆盖平台 |
| `coverage_check` | 六类条数 vs ≥2；总数 vs ≥15 |
| `escalation` | 需开发者定夺清单（含为什么 FAQ 不能定） |
| `consistency_check` | 价格/上限/隐私承诺与落地页逐字一致核对 |

## 使用步骤

### 方式一：纯提示词

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供 subject + known_questions（真实收集的问题）
3. 得到问答清单 + 覆盖度检查 + 需定夺清单；开发者逐条确认后生效

### 在发布时间轴中的位置

- **T-7**：launch-kit-generate-flow 产出素材三件套（含本技能初稿）
- **T-3**：素材定稿时同步定稿口径库（新增信息回填）
- **T-0/T+1**：daily-comment-duty-flow 的 P2 疑问按本库关键词匹配回复

## 边界（不做的事）

- ❌ 不编造数据上限、兼容范围、性能数字——没有就标「需开发者提供」
- ❌ 不写「高度重视用户隐私」类公关空话——写数据流向事实
- ❌ 不承诺未定日期与功能；法律问题（许可证/合规）一律转人工
- ❌ 不回避攻击性问题——预演不敢答的发布日更答不了
- ❌ 英文版不从中文版机翻——各自重写，事实口径一致

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "subject": "ClipMate：本地存储、免费+Pro $8/月、支持 Win10/11、一人独立开发、竞品为 Ditto",
  "known_questions": ["和 Ditto 有什么区别？", "为什么不开源？", "剪贴板数据会上传吗？"]
}
```

**输出**（见 examples/output.md）：8 条核心口径（含「一个人做的敢用吗」的兜底回答：
数据全程本机 + 停更放导出工具）；覆盖度检查显示距 ≥15 条差 7 条并列补充清单；
3 个问题标「需开发者定夺」。

## 所属工作流

- `launch-kit-generate-flow`（发布素材包生成，T-7 启动，本技能为三件套之一）
- `daily-comment-duty-flow`（发布日值守时按关键词匹配本库）

## 合规声明

- 输出标注「AI 生成内容」，口径库经开发者逐条确认后生效
- 引用的用户数据/评价须获授权；隐私承诺与隐私政策实际内容一致
- 不承诺路线图外功能；法律口径一律转人工
