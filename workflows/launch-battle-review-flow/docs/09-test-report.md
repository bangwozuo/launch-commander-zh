## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 数据由用户提供 | 指标（后台导出）与评论（值守积累）不代抓 |
| 采样偏差 | 脚本无法识别「只存了好评」——采样纪律靠人工在复盘会核对 |
| 时间窗 | PV 与评论窗口可能不齐，交叉时标注各自窗口 |
| 归因边界 | 脚本只出漏斗层提示；高光/失误/建议由模型撰写、人工确认 |
