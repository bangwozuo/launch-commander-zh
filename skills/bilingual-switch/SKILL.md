# 中英双语切换

中文社区与英文社区受众、语感、笑点完全不同——产出两套**各自原生**的文案，
口号：**重写，不是互译（rewrite, not translate）**。

不做的事：不做逐句翻译、不翻产品名、不替用户定 tagline 翻不翻（两案并列供选）。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_02_sk05` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 发布指挥官 |
| 能力族 | 文案生成型 · 双语重写与口径一致 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高（每次双语发布/FAQ/邮件复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **事实骨架法**：先抽不可变事实（功能/数字/价格/承诺），两版逐条对照——
   口径漂移 = 信任事故
2. **五步重写流**：抽骨架 → 定各自重点（英文 privacy/pricing 优先，中文 能不能用/
   为什么做）→ 各自成文 → 术语核对 → 事实回对
3. **Chinglish 自查 7 项**：very 滥用 / 中式搭配 / welcome to use / 主语一致 /
   冠词单复数 / 专名大小写 / 成语硬翻
4. **翻译腔自查 5 项**：公文腔 / 「您」/ 被动态 / 数字单位习惯 / 英文语序残留
5. **术语类型规则**：产品名永不翻译；tagline 重写非直译；技术词用目标社区通行叫法；
   单位换算（10 万 → 100k）；文化梗各自原生不硬搬
6. **社区语感对照表**：人称/语气/句长/emoji/谦辞 六维对照（PH vs V2EX/即刻）

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | string | ✅ | 原文案（单语言完整版） |
| `target_lang` | string | ✅ | English（PH/Reddit/X）/ 中文（V2EX/即刻）/ 双向 |
| `glossary` | object | ⬜ | 指定译法；未指定按类型规则执行 |
| `audience_en` / `audience_zh` | string | ⬜ | 两边受众 |

## 输出规格

| 件 | 说明 |
|---|---|
| `fact_skeleton` | 事实骨架对照表（含一致 ✅） |
| `rewritten` | 各语言重写稿全文 |
| `glossary_applied` | 术语处理记录 |
| `self_check` | Chinglish 7 项 + 翻译腔 5 项 + 事实一致性逐条勾选 |

## 使用步骤

### 方式一：纯提示词

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供原文案 + 目标语言社区 + 术语表（如有）
3. 得到事实骨架 + 两版重写稿 + 自查清单；人工确认后发布

### 在流程中的位置

- `producthunt-copy`（英文原稿）/ `platform-format-adapt`（多平台版本）→ 本技能做双语
- 事实口径库来自 `faq-pregenerate`（价格/数字逐字一致）

## 边界（不做的事）

- ❌ 不做逐句互译；不交不能通过自查清单的句子
- ❌ 不翻译产品名；不擅自决定 tagline 翻不翻（两案并列让用户选）
- ❌ 两版事实口径必须一致——任一版改动须同步另一版
- ❌ 不编造某一边社区的文化梗（用错梗比不用更尴尬）
- ❌ 不用机器翻译腔兜底

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "content": "中文版主稿（V2EX）：做了两年…第 7 次的时候破防了…只存本机 SQLite…0.3 秒命中…免费 + Pro $8/月。",
  "target_lang": "English（PH/Reddit 社区）",
  "glossary": {"ClipMate": "不翻译", "10 万条": "100k entries", "$8/月": "$8/mo"}
}
```

**输出**（见 examples/output.md）：英文版以「the 7th one broke me」重写「破防」梗；
7 项事实骨架全部一致；Chinglish 扫描 7 项全过；tagline 两案并列供选。

## 所属工作流

- `multi-platform-copy-adapt-flow`（多平台文案适配，双语切换为其中一环）

## 合规声明

- 输出标注「AI 生成内容」，两版均人工确认后发布
- 用户指定译法严格按术语表执行；两版引用的评价/数据同源同授权
- 价格/数字/承诺两版一字不差，改动须双版同步
