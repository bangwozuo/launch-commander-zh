## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 夏令时 | 按 PDT(UTC-7)/EDT(UTC-4) 基线偏移；跨夏令时切换日的发布须人工复核 |
| 时点为经验值 | 平台时点基线需定期校准；未收录平台标待补充 |
| 不执行发布 | 产出日历与清单；执行、打勾、发布全部人工 |
| 平台内规则 | Reddit 各 sub 版规差异需 T-1 人工确认 |
