### 示例 1：Product Hunt 文案

**能力**：生成 tagline/首评/maker comment 全套 PH 文案

**输入**：

```json
{
  "product_info": {
    "名称": "冰丝防晒衣",
    "材质": "锦纶 + 氨纶",
    "卖点": [
      "UPF50+",
      "可拆卸帽檐"
    ]
  }
}
```

**输出**：

## 优化后标题

夏季冰丝防晒衣 男女同款 轻薄透气 UPF50+ 防晒外套 可拆卸帽檐

## 卖点清单

1. **UPF50+ 硬防晒** — 可提供检测报告编号
2. **冰丝凉感材质** — 锦纶 + 氨纶混纺，客服可提供成分表
3. **可拆卸帽檐** — 一衣两穿，通勤与户外通用

## 合规扫描

- 结论：**通过**
- 违规词：无（已规避「最好」「第一」「国家级」等极限词）

**资产位置**：`skills/producthunt-copy/`

## 要点摘要

开发者在冷启动期最缺的不是执行力，而是「在哪个渠道、对谁、说什么」的判断依据。

## 痛点清单

1. **选题无依据** — 凭感觉发内容，不知道哪条会有效（来源 1、3）

## 情绪倾向

偏负面 — 多数帖子在描述「投入多但反馈少」的挫败感

## 证据索引

- 来源 1：日更 30 天，仅 2 条内容带来有效转化
- 来源 2：5 个平台来回切，最后都荒废

### 示例 9：战报生成

**能力**：多平台发布数据汇总成复盘长文

**输入**：

```json
{
  "data": {
    "曝光": 12000,
    "点击": 480,
    "转化": 32
  }
}
```

**输出**：

## 核心结论

本周曝光增长 62% 来自 Reddit 单帖爆发，其余渠道基本持平。

## 驱动因素

1. **Reddit 热帖** — 贡献 62% 增量，帖子进入 subreddit 首页
2. **X 转发** — 贡献 18%，主要来自 2 个 KOL 转发
3. **自然搜索** — 贡献 12%，长尾词开始见效

## 置信度

**中** — 数据来源为用户手动导出，样本周期仅 1 周

## 下一步行动

1. 拆解那条 Reddit 热帖的结构（标题 / 首段 / 配图 / 发布时间）
2. 下周复用该结构发 3 篇，验证可复制性
3. X 侧主动联系 5 个同领域 KOL，建立长期关系

**资产位置**：`skills/battle-report-generate/`
