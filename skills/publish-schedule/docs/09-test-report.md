## 三、SOP 走查

| 走查项 | 结果 |

| 人工确认点 | 七节点全部有确认点；FAQ 逐条确认不许批处理 ✅ |

## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 时点为经验值 | 各平台流量时点基于公开经验整理，以平台数据为准定期校准 |
| 无自动执行 | SOP 只产出日历与清单；执行、打勾、发布全部人工 |
| 时区换算 | 换算由模型完成并标注，闹钟设置须人工复核 |
| 版规时效 | Reddit 等版规会变，T-1 清单执行时以当日版规为准 |

**通过。** SOP 四件（日历/清单/时点表/升降级）齐全，人工确认点七节点全覆盖，
