## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 依赖产品事实 | 上限数字、隐私架构等由开发者提供；提供错则口径错，发布前须逐条确认 |
| 覆盖度依赖输入 | known_questions 越真实预演越准；空输入时按六类模板从零预演 |
| 规则时效 | 各社区评论规范以官方为准 |
| 语感 | 英文口径建议母语者终审（尤其 PH 首日） |
